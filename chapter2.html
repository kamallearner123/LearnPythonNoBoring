Chapter 2: Making Python Talk and Listen

1. The print() Megaphone

The most basic thing we can do in programming is tell the computer to display a message. We do this using the print() function. Think of it like a megaphone for your code!

Example A: Printing a Number

print(42)

Example B: Printing a Sentence

print("Python is awesome!")
Assignment 1: Self-Introduction Card

2. Printing Multiple Things Together

You can print multiple things on the same line by separating them with a comma ,. Python automatically adds a space between them.

Example A: Combining Text and Numbers

print("I am", 12, "years old")

Example B: Making a List

print("Apples", "Bananas", "Cherries")
Assignment 2: The 3-Line Poem

3. Adding Blank Lines

If you just use print() with nothing inside the parentheses, Python will print a blank line. This helps make your output easier to read!

Example A: A Simple Gap

print("Line 1")
print()
print("Line 2")

Example B: Multiple Gaps

print("Top")
print()
print()
print("Bottom")
Assignment 3: Spacing It Out

4. The input() Microphone

Printing is fun, but what if we want to ask the user a question? We use the input() function. It waits for the person using your program to type something in.

Example A: Asking for a Name

user_name = input("Who goes there? ")
print("Welcome,", user_name)

Example B: Asking for an Age

age = input("How old are you? ")
print("Wow, you are", age, "years old!")
Assignment 4: Emoji Generator

5. Talking Back to the User

We can take what the user typed in (using input()) and use it in our print() spells to make the computer seem smart!

Example A: Echoing Output

color = input("What is your favorite color? ")
print(color, "is a great color!")

Example B: Creating a Full Sentence

food = input("What did you eat for breakfast? ")
print("I bet that", food, "was delicious.")

Chapter 18: Machine Learning (Part 2 - Models & Pipelines)

1. Decision Trees & Random Forests

A Decision Tree breaks down complex choices into a sequence of binary (Yes/No) questions. A Random Forest combines dozens of different trees into an ensemble committee that votes on the final answer to prevent errors!

Assignment 1: Random Forest Ensemble Voting

2. Linear Regression (Predicting Continuous Numbers)

While Classification predicts categories (Cat vs Dog), Regression predicts continuous numerical quantities (House Prices, Temperature, Test Scores).

Linear Equation: y = m · x + b
Where m = slope (rate of change) and b = intercept (base value).
Assignment 2: Simple Linear Regression Model

3. The Scikit-Learn API Workflow (`fit`, `predict`, `score`)

In industry Python code, engineers use scikit-learn (sklearn). All algorithms follow the exact same 4-step blueprint:

  1. Instantiate: model = DecisionTreeClassifier()
  2. Train: model.fit(X_train, y_train)
  3. Predict: predictions = model.predict(X_test)
  4. Evaluate: acc = accuracy_score(y_test, predictions)
Assignment 3: Scikit-Learn Paradigm Simulator

4. Beyond Accuracy: Precision, Recall & Confusion Matrix

Simple Accuracy can be misleading! For example, if 99% of emails are NOT spam, a model that predicts "Never Spam" is 99% accurate, but completely useless!

  • True Positive (TP): Spam correctly identified as Spam.
  • False Positive (FP): Important email wrongly flagged as Spam (False Alarm).
  • False Negative (FN): Dangerous Spam missed by filter.
  • Precision Formula: TP / (TP + FP) → How trustworthy are positive predictions?
  • Recall Formula: TP / (TP + FN) → What fraction of actual positives did we catch?
Assignment 4: Precision and Recall Calculator

5. Saving & Loading Models (Model Persistence)

Training an AI on gigabytes of data can take days or weeks! In production, we train once, serialize the trained weights/parameters into a file (using pickle, joblib, or json), and load it instantly in our web app!

Chapter 18: Machine Learning (Part 2)

Note: Real ML libraries take a long time to load. We've provided a Lightning-Fast Mock ML library that uses the exact same syntax as the pros use!

1. The Model

In the real world, we use a library called sklearn to build models. A popular model is the Decision Tree. It asks a bunch of Yes/No questions to learn!

Example A: Creating the Model

model = DecisionTreeClassifier()
Assignment 1: Build the Brain

2. Training the Model (.fit)

Once you have a model, you have to teach it! You pass in your Features (X) and your Labels (y) using the .fit(X, y) method.

Example A: Training

model.fit(X, y)
Assignment 2: Study Time!

3. Making Predictions (.predict)

After studying, the model is ready for a test! You use the .predict() method and pass in a NEW set of features it has never seen before.

Example A: Predicting

answer = model.predict([[5]])
Assignment 3: The Crystal Ball

4. Evaluating the Model

How do we know if our AI is smart? We test it against a set of answers we already know, and calculate its Accuracy Score (like grading a test out of 100%).

Example A: Grading the AI

score = accuracy_score(true_y, guessed_y)
Assignment 4: Grading the Test

5. Saving the Model

Training an AI can take days or weeks! Once it is trained, we save its "brain" to a file so we don't have to train it again. We use a tool called `pickle` or `joblib` for this.

Assignment 5: Pickling the Brain

Chapter 11: The Magical Map (Dictionaries)

1. What is a Dictionary?

A list is like a backpack where items are ordered by numbers (0, 1, 2). A Dictionary is like a magical map where you look things up using a name (a Key) to find a treasure (a Value). We use curly braces {} to make them.

Example A: Creating a simple dictionary

player = {"name": "Zelda", "health": 100}

Example B: Looking up a value

print(player["name"]) # Prints 'Zelda'
Assignment 1: The Monster Stats

2. Adding and Updating Keys

You can easily add new markers to your map or change existing ones. Just write the name of the new key in brackets and set it equal to something!

Example A: Adding a new key

player["weapon"] = "Sword"

Example B: Updating an existing key

player["health"] = 80 # Took damage!
Assignment 2: Level Up!

3. Removing Keys

If a treasure gets stolen from the map, you can use the del keyword to delete that key-value pair completely.

Example A: Deleting a key

del player["weapon"]

Example B: The .pop() method

item = player.pop("health") # Removes health and returns it
Assignment 3: Stolen Gold

4. Looping Through Dictionaries

You can use a for loop to go through all the keys in a dictionary. You can also use .values() or .items() to loop through the values or both!

Example A: Looping through keys

for k in player: print(k)

Example B: Looping through items (keys and values)

for k, v in player.items(): print(k, v)
Assignment 4: The Vendor's Wares

5. Nested Dictionaries

Maps within maps! You can put a dictionary INSIDE another dictionary to organize lots of complex information.

Example A: A nested dictionary

monsters = {"dragon": {"hp": 500}}

Example B: Accessing nested data

print(monsters["dragon"]["hp"])

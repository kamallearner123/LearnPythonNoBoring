Chapter 11: The Magical Map (Dictionaries & Sets)

1. What is a Dictionary? (Key-Value Pair Hashing)

A list stores items by zero-based numerical index. A Dictionary (or dict) maps unique, immutable Keys to Values using a Hash Table under the hood. Looking up a key takes instantaneous $O(1)$ constant time!

Assignment 1: Defining & Accessing Dictionaries

2. Safe Lookups with `.get()` & Modifying Keys

If you try to access a non-existent key with dict["missing"], Python throws a KeyError! Use .get(key, default) for safe lookups that return a fallback default instead of crashing.

Assignment 2: Safe Key Lookups with .get()

3. Iterating Dictionaries (`.keys()`, `.values()`, `.items()`)

You can loop over keys, values, or both simultaneously using .items() which unpacks key-value tuple pairs!

Assignment 3: Iterating Key-Value Pairs

4. Dictionary Comprehensions

Just like List Comprehensions, you can transform or filter dictionaries using concise {key: value for item in iterable} syntax!

Assignment 4: Dictionary Comprehension

5. Sets & Mathematical Set Operations

A Set (set) is an unordered collection of unique items (no duplicates). Sets support fast mathematical operations like Union (|), Intersection (&), and Difference (-)!

Assignment 5: Mathematical Set Operations

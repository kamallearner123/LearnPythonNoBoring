Chapter 1: Welcome to the Magic of Python

1. What is Python?

Imagine you have a magical spellbook. By writing specific words inside it, you can make a computer do exactly what you want! Python is the language of those spells. It's one of the most popular programming languages in the world because it's powerful, but also super easy to read.

2. Setting Up Your Magic Wand (Python)

In this interactive book, you can run all your spells right here in your web browser! But to become a true wizard, you'll want to install Python on your own computer eventually.

Assignment 1: Install Python

Go to python.org/downloads and download Python. If you are on Windows, make sure to check the box that says "Add python.exe to PATH" before you install!

3. The Magic Notebook (Jupyter)

Real programmers often use a tool called Jupyter Notebook to write their code. It lets you write code and see the results instantly, just like the interactive boxes in this book.

Assignment 2: Install Jupyter

Open your Command Prompt (Windows) or Terminal (Mac/Linux) and type this command: pip install notebook

4. How to Run Your First Spell

Let's cast our first spell! We will use the print() spell to make the computer talk.

Assignment 3: Open a Notebook

If you installed Jupyter, type jupyter notebook in your terminal to open it. Create a new "Python 3" file.

Example A: Python is easy

print("Python is like English!")

Example B: Fast execution

print("It runs instantly!")

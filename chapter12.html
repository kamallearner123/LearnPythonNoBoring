Chapter 12: Building Blueprints (Classes)

1. What is Object-Oriented Programming?

Imagine you want to build 100 robot dogs. Instead of building each one from scratch, you'd draw a single Blueprint (a class). Then you use that blueprint to build the physical robots (the Objects).

Example A: Creating an empty class

class RobotDog: pass

Example B: Creating an object from the class

my_robot = RobotDog()
Assignment 1: Your First Blueprint

2. The __init__ Function

When you build a robot from a blueprint, you want to set it up right away (give it a name, a color). Python has a special magical setup function called __init__ that runs the moment the object is built.

Example A: Setting up an object

def __init__(self, name): self.name = name

Example B: Passing the setup info

fido = RobotDog("Fido")
Assignment 2: Naming the Robot

3. Object Attributes

The variables that live inside an object (like sparky.name or sparky.battery) are called Attributes. You can change them just like normal variables!

Example A: Reading an attribute

print(sparky.color)

Example B: Changing an attribute

sparky.battery = 50
Assignment 3: Draining the Battery

4. Object Methods

Functions that belong to an object are called Methods. They allow the object to *do* things, like bark, walk, or calculate!

Example A: Defining a method

def bark(self): print("Woof!")

Example B: Calling a method

sparky.bark()
Assignment 4: Teaching the Dog to Bark

5. Multiple Objects

The best part about blueprints is that you can build as many robots as you want, and they all act independently!

Example A: Two different objects

dog1 = RobotDog("Rex")
dog2 = RobotDog("Spot")

Example B: They have different data

dog1.bark()
dog2.bark()
Assignment 5: The Robot Army

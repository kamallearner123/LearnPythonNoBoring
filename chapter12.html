Chapter 12: Building Blueprints (Classes & OOP)

1. Object-Oriented Programming (Classes vs Instances)

Object-Oriented Programming (OOP) structures software around real-world objects. A class is the architectural Blueprint, while an object (or instance) is a concrete item constructed from that blueprint!

Assignment 1: Defining a Class & Instantiate Objects

2. Instance Methods & Encapsulation

Methods are functions defined inside a class that operate on the object's instance attributes using the self parameter. Encapsulation bundles state and behavior together!

Assignment 2: Object Methods & State Mutation

3. Class Attributes vs Instance Attributes

An Instance Attribute is unique to each individual object (e.g. self.name). A Class Attribute is shared across all instances of that class!

Assignment 3: Shared Class Attributes

4. Inheritance & Method Overriding (`super()`)

Inheritance allows a child class to inherit attributes and methods from a parent class. The child can add new features or override parent methods using super().

Assignment 4: Class Inheritance & Method Overriding

5. Dunder / Magic Methods (`__str__`, `__repr__`, `__len__`)

Special methods surrounded by double underscores (Dunder Methods) customize built-in Python behaviors for your objects (e.g. __str__ controls string representation when printed!).

Assignment 5: Implementing __str__ and __len__

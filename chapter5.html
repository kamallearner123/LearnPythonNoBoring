Chapter 5: Words, Sentences, and Emojis

1. Creating Strings

In Python, text is called a String (because it's a string of characters tied together). You create a string by putting text inside single quotes 'like this' or double quotes "like this".

Example A: Double quotes

print("Hello")

Example B: Single quotes

print('World')

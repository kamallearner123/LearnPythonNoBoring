Chapter 21: Data Wrangling (Pandas)

1. What is Pandas? (Series & DataFrames)

Pandas is Python's premier data manipulation library. It introduces two fundamental data structures:

  • pd.Series: A 1D labelled array (like a single column with row indexes).
  • pd.DataFrame: A 2D labelled tabular data structure (like an Excel spreadsheet or SQL table with rows and columns).
Assignment 1: Building & Inspecting a DataFrame

2. Data Selection & Filtering (`loc` vs `iloc`)

Pandas provides specialized indexing methods for precise row & column extraction:

  • df["ColName"]: Extracts a specific column Series.
  • df.loc[row_label, col_label]: Selects data using string labels and boolean conditions.
  • df.iloc[row_idx, col_idx]: Selects data using integer positions (0-based indexing).
Assignment 2: Selection & Conditional Filtering

3. Data Cleaning & Handling Missing Values (`NaN`)

Real-world datasets contain missing values (represented as NaN or None). Pandas makes it easy to detect missing data with .isnull(), remove them with .dropna(), or impute default values using .fillna()!

Assignment 3: Imputing Missing Values

4. Grouping & Aggregating Data (`groupby`)

The .groupby() method follows the Split-Apply-Combine workflow: it splits data into category buckets, applies aggregate math functions (like mean(), sum(), count()), and combines the results!

5. Merging & Joining DataFrames (`pd.merge`)

You can combine multiple DataFrames sharing a common key using SQL-style joins: inner, outer, left, or right with pd.merge()!

Chapter 9: The Magic Backpack (Lists)

1. What is a List?

A variable can only hold one thing at a time. But a List is like a magic backpack that can hold as many things as you want! You create a list using square brackets [].

Example A: Creating a list

inv = ["Sword", "Shield"]

Example B: Printing it

print(inv)

2. Accessing Items (Indexes)

Every item in your backpack has a secret compartment number, starting at 0. The first item is at index 0, the second is at index 1, and so on.

Assignment 2: Pick the 3rd Game

3. Adding Items

You can always add more stuff to your backpack using the .append() spell. It adds the new item to the very end of the list.

Assignment 3: Add a New Game

4. Removing Items

If you don't want something in your backpack anymore, you can throw it out using the .remove() spell.

5. Choosing Random Items

Python has a magical random library. You can use random.choice() to close your eyes, reach into your backpack, and pull out a random item!

Chapter 14: The Ancient Scrolls (File I/O, CSV & JSON)

1. Context Managers (`with open(...) as f:`)

Opening files with open() requires manually calling .close(). If an error happens before closing, file descriptors leak! Using a Context Manager (with open(...) as f:) guarantees automatic file closure even if exceptions occur.

Modes: 'r' (Read), 'w' (Write/Overwrite), 'a' (Append), 'r+' (Read/Write)
Assignment 1: Context Manager File Writing & Reading

2. Reading Modes (`read`, `readline`, `readlines`)

Python provides 3 methods to extract text from files depending on memory constraints:

  • .read(): Reads the ENTIRE file into a single string.
  • .readline(): Reads a single line at a time.
  • .readlines(): Reads all lines into a list of strings.
Assignment 2: Exploring File Reading Methods

3. Working with Tabular CSV Data (`csv` module)

CSV (Comma-Separated Values) files store tabular spreadsheet data. Python's built-in csv module allows reading and writing structured tables using csv.reader and csv.writer!

Assignment 3: Reading and Writing CSV Data

4. JSON Serialization & Parsing (`json` module)

JSON (JavaScript Object Notation) is the standard format for web API data. Python's json module converts Python dictionaries/lists to JSON strings with json.dumps() and parses JSON with json.loads()!

Assignment 4: JSON File Storage & Parsing

5. In-Memory Virtual File Processing (StringIO)

For fast in-memory data streams without writing to real disk storage, Python's io.StringIO mimics a file interface inside memory buffer RAM!

Assignment 5: Memory Buffer Streams with io.StringIO

Chapter 14: The Ancient Scrolls (File I/O)

Note: In our magical browser editor, files are saved in temporary browser memory. When you refresh, they disappear!

1. Opening a File

To read or write an ancient scroll (a text file), you must first open() it. You have to tell Python the name of the file and whether you want to read ('r') or write ('w').

Example A: Opening to Write

file = open("secret.txt", "w")

Example B: Opening to Read

file = open("secret.txt", "r")
Assignment 1: Unfurl the Scroll

2. Writing to a File

Once a file is open in 'w' mode, you can use .write() to put text inside it. Warning: 'w' mode deletes anything that was previously in the file!

Example A: Writing text

file.write("Hello World!")

Example B: Adding a new line

file.write("\nThis is line two.")
Assignment 2: Inscribing the Spell

3. Reading a File

If you open a file in 'r' mode, you can use .read() to pull all the text out of the file and save it into a string variable.

Example A: Reading everything

content = file.read()

Example B: Reading one line

line1 = file.readline()
Assignment 3: Reading the Ancient Words

4. Appending to a File

If you don't want to erase the file when you write to it, use append mode ("a"). This adds new text to the very end of the file.

Example A: Append Mode

file = open("log.txt", "a")

Example B: Appending text

file.write("Another entry!")
Assignment 4: The Diary

5. The with Keyword

Programmers often forget to .close() their files. To fix this, you can use the with keyword. It automatically closes the file for you as soon as the block is done!

Example A: The with block

with open("file.txt", "r") as f:

Example B: Automatic closing

    print(f.read()) # Closes automatically!

Chapter 10: Building Your Own Tools (Functions)

1. What is a Function?

So far, we've used tools built by other people (like print() and len()). But you can build your own custom tools! We call these tools Functions. You create them using the def magic word (which stands for "define").

Example A: Defining a function

def say_hi():
    print("Hi!")

Example B: Calling it

say_hi()

2. Giving Ingredients (Arguments)

Functions are like blenders. You can put ingredients into them (called Arguments), and they will use those ingredients to do their job.

3. Getting a Result (Return)

If you put strawberries in a blender, you expect a smoothie to come out. In Python, you can use the return keyword to make a function spit a result back out to you.

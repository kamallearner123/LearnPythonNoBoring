Chapter 10: Building Your Own Tools (Functions)

1. What is a Function?

A Function is a reusable block of code designed to perform a specific task. Functions prevent code duplication (the DRY principle: Don't Repeat Yourself). We define them using the def keyword.

Assignment 1: Defining & Calling Functions

2. Positional Arguments, Keyword Arguments & Defaults

Functions accept inputs called Parameters. You can pass them as Positional Arguments or specify them explicitly as Keyword Arguments. Parameters can also have Default Values!

Assignment 2: Parameters with Default Values

3. Return Values & Unpacking Multiple Returns

Instead of just printing inside a function, the return keyword sends results back to the caller. Python functions can even return multiple values packed inside a tuple!

Assignment 3: Returning Multiple Values

4. Scope: Local vs Global Variables

Variables created inside a function are Local and disappear when the function finishes. Variables created outside are Global. If you want to modify a global variable inside a function, use the global keyword.

Assignment 4: Managing Local and Global Scope

5. Lambda Functions & Higher-Order Functions

A Lambda Function is an anonymous, single-line function defined with lambda arguments: expression. They are often passed as arguments into functions like sorted(), filter(), and map().

Assignment 5: Anonymous Lambda Functions

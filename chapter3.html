Chapter 3: Magical Memory Boxes

1. What are Variables?

Imagine your computer has millions of tiny magical boxes inside it. When we write a program, we use these boxes to store information we want the computer to remember. In Python, these boxes are called Variables.

Creating a variable is like putting a label on a box and putting something inside using the equals sign =.

Assignment 1: High Score Box

2. Naming Rules

You can name your boxes almost anything, but there are rules! Variables can't have spaces (use underscores `_` instead), and they can't start with a number.

Example A: Good name

player_score = 50

Example B: Bad name

# 1player = 50 (This crashes!)

3. Updating Variables

The best thing about variables is that they can vary (change)! If you put something new into an existing box, the old thing disappears.

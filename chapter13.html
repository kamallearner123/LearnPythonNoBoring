Chapter 13: Catching Bugs (Error Handling)

1. Python Exceptions & Tracebacks

When runtime operations encounter invalid inputs or state (e.g. dividing by zero or converting non-numeric text), Python raises an Exception. If unhandled, exceptions halt script execution and print a traceback trace.

Assignment 1: Unhandled Exceptions & Traceback Inspection

2. Basic `try...except` Handling

Wrap risky statements inside a try block. If an error occurs, control transfers immediately to the except block, preventing script crashes!

Assignment 2: Basic try...except Block

3. Catching Multiple Specific Exceptions & Inspecting Error Objects

Different bugs require different remedies. Use specific exception types (e.g. ValueError, ZeroDivisionError) and inspect error strings using as err!

Assignment 3: Specific Exception Handlers

4. Complete Pipeline: `try`, `except`, `else`, and `finally`

Python exception handling supports 4 complementary blocks:

  • try: Code that might fail.
  • except: Code executed ONLY if an error occurred.
  • else: Code executed ONLY if NO error occurred.
  • finally: Cleanup code executed ALWAYS (regardless of errors).

You can trigger exceptions manually using raise, and define custom business-logic exceptions by inheriting from Python's base Exception class!

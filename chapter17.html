Chapter 17: Machine Learning (Part 1)

1. What is Machine Learning?

Normally, we give computers rules: "If weight > 50, it is a dog." But in Machine Learning, we give the computer examples (data) and let it figure out the rules on its own!

Example A: Traditional Code

if weight > 20: animal = "Dog"
Assignment 1: Hardcoded Rules vs ML

2. Features (The Clues)

When teaching a computer to tell a dog from a cat, we use Features. Features are clues like "weight", "ear shape", or "bark pitch". We usually put them in a list.

Example A: A single animal's features

animal_1 = [15, 2] # 15 lbs, ear shape 2
Assignment 2: Collecting Clues

3. Labels (The Answers)

If we want the computer to learn, we have to give it the answers to study from. These answers are called Labels. "0" might mean Cat, and "1" might mean Dog.

Example A: Label list

labels = [0, 1] # Cat, Dog
Assignment 3: Defining the Answers

4. The Dataset (X and y)

In Machine Learning, we combine all the features into a big list of lists called X (capital X), and all the answers into a list called y (lowercase y).

Example A: X and y

X = [[15], [60]]
y = [0, 1]
Assignment 4: Building the Dataset

5. The Goal of Training

The goal is to feed `X` and `y` into a magical math box (the Model). The Model studies them and creates its own rules, so when a new animal appears, it can guess the label!

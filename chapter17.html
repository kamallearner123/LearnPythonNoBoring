Chapter 17: Numerical Magic with NumPy 🔢

1. What is NumPy? (Lists vs Vectorized N-Dimensional Arrays)

NumPy (Numerical Python) is the foundational library for scientific computing and Machine Learning in Python. Standard Python lists are slow because they store pointers to objects scattered in memory. NumPy arrays (np.ndarray) store homogeneous data in contiguous C-memory blocks, making mathematical operations up to 50x faster!

Assignment 1: Creating & Inspecting NumPy Arrays

2. Array Shapes, Reshaping & Multi-Dimensional Slicing

You can inspect an array's dimensions with .shape, change its dimensions without altering data using .reshape(rows, cols), and slice specific rows or columns using arr[row_slice, col_slice]!

Assignment 2: Reshaping & Matrix Slicing

3. Vectorized Operations & Broadcasting

In NumPy, you never write for loops for math! Operations are automatically vectorized across all elements simultaneously. Broadcasting allows NumPy to perform operations between arrays of different shapes!

Assignment 3: Vectorized Operations & Broadcasting

4. Boolean Masking & Conditional Filtering

A Boolean Mask is an array of True/False values created by logical conditions (e.g. arr > 50). Passing a mask into an array instantly filters out only the matching elements!

Assignment 4: High-Speed Boolean Filtering

5. Statistical Aggregations & Axis Operations

NumPy provides lightning-fast statistical routines. You can compute statistics across the entire matrix, column-by-column (axis=0), or row-by-row (axis=1)!

Chapter 17: Machine Learning (Part 1 - Foundations)

1. What is Machine Learning? (Rules vs Data)

In classical programming, we write hardcoded rules by hand:

Traditional Coding: Data + Hardcoded Rules → Answers
Machine Learning: Data + Answers (Labels) → Machine Discovers Rules!

Instead of manually guessing rules like if weight > 20 and ears == 'pointy', we feed thousands of examples to the computer and let math find the pattern.

Assignment 1: Hardcoded Rules vs Pattern Matching

2. The Three Pillars of Machine Learning

Machine Learning is divided into three primary paradigms:

  • Supervised Learning: Learning with a teacher. The dataset has inputs ($X$) and target answers ($y$). Examples: Spam filtering, house price prediction.
  • Unsupervised Learning: Learning without answers. Finding hidden clusters or patterns in unlabelled data. Examples: Customer segmentation, anomaly detection.
  • Reinforcement Learning: Learning through trial, error, and feedback rewards. Examples: Game-playing AI (Chess, Mario), self-driving cars.
Assignment 2: Unsupervised Clustering Simulation

3. Features ($X$), Labels ($y$) & Feature Scaling

To teach a machine, we convert real-world items into numbers:

  • Features ($X$): Matrix of input measurements (e.g. [weight_lbs, height_inches, ear_length]).
  • Labels ($y$): Target vector of answers (e.g. 0 = Cat, 1 = Dog).
  • Feature Normalization: Scaling features so large numbers (weight in grams) don't overpower small numbers (ear length in inches). Formula: (x - min) / (max - min).
Assignment 3: Normalizing Features

4. Distance & Similarity (K-Nearest Neighbors Algorithm)

One of the simplest real Machine Learning algorithms is K-Nearest Neighbors (KNN). To classify a new sample, it measures the Euclidean Distance to all known samples and selects the majority vote among its nearest neighbors!

Euclidean Distance Formula:

d = √((x1 - x2)2 + (y1 - y2)2)
Assignment 4: Build a 1-NN Classifier from Scratch

5. Training Data vs Testing Data Split

Why shouldn't we test our ML model on the exact same data it learned from? Because it might just memorize the answers (Overfitting) instead of learning real patterns (Generalization)!

We split our dataset into a Training Set (80%) to let the model learn, and a Testing Set (20%) to grade its performance on unseen data.

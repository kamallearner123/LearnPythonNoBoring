Chapter 0: Setting Up Your Computer

In this book, you can run all the code right here in your browser! But if you want to become a true Python master, you'll eventually want to install Python on your own computer. This chapter will show you how.

1. Installing Python

Python is the engine that runs your code. Getting it is completely free!

  • Step 1: Go to the official Python website at python.org/downloads.
  • Step 2: Click the big yellow button that says "Download Python". (It will automatically find the right version for Windows, Mac, or Linux).
  • Step 3: Open the downloaded file. IMPORTANT: If you are on Windows, make sure to check the box that says "Add python.exe to PATH" at the very bottom before you click Install!
  • Step 4: Click "Install Now" and wait for it to finish.

2. Installing Jupyter Notebook

Jupyter Notebook is an awesome tool used by real data scientists and game developers. It lets you write code and see the results side-by-side, just like in this book!

To install Jupyter, we use a tool called pip (which comes with Python). Follow these steps:

Terminal / Command Prompt
# For Windows: 1. Press the Windows Key and type "cmd" to open the Command Prompt. 2. Type the following command and press Enter: > pip install notebook # For Mac / Linux: 1. Open the "Terminal" app. 2. Type the following command and press Enter: $ pip3 install notebook

3. Starting Jupyter Notebook

Once it is installed, starting it is super easy.

Terminal / Command Prompt
# In your Command Prompt or Terminal, type: > jupyter notebook

A new tab will pop open in your web browser. From there, you can click "New" -> "Notebook" -> "Python 3" to create your very first Python file on your own computer!
